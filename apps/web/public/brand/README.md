# SwarmPay brand and cover kit

Start with **swarmpay-cover-devpost.png** for the project gallery. It is 1800 × 1200 pixels, follows Devpost's recommended 3:2 shape, and is below the 5 MB upload limit.

| File | Use |
| --- | --- |
| swarmpay-cover-devpost.png | Devpost project thumbnail or cover |
| swarmpay-cover-wide.png | 1920 × 1080 video title or presentation cover |
| swarmpay-cover-social.png | 1200 × 630 link preview |
| swarmpay-brand-palette.png | Color and type reference |
| swarmpay-payment-states.png | Proposed UI polish, explicitly an illustrative design specification |
| Matching .svg files | Editable vector artwork; lettering is outlined for reliable display |
| brand-tokens.css / brand-tokens.json | Proposed colors, typography and sizing for implementation |
| contrast-checks.json | Calculated foreground/background contrast results |
| art-direction.md | Creative brief, exact copy and provenance |
| fonts/ | Manrope and DM Sans, with their Open Font Licenses |

The palette keeps Evergreen **#11695B** and adds Citron **#D5FF5F**, Sky **#A9E7FF**, Deep ink **#142F2B**, Cloud **#F7FAF7**, and Slate **#52665F**. Use dark text on bright colors. Reserve distinct semantic treatments for paid, awaiting delivery, and held requests.

The covers are original vector illustrations, not screenshots, payment evidence or AI-generated raster images. The product specimen is a proposed treatment, not the current website. No application styles or live services were changed.

The complete review is in `../../pdf/swarmpay-hackathon-review-2026-11-10.pdf`, with an editable Markdown copy beside it.
