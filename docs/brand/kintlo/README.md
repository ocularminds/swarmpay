# Kintlo commercial brand kit

**Kintlo** is the selected commercial name. These are prepared launch assets; the current hackathon identity remains SwarmPay. Read [brand-decision.md](brand-decision.md) for the name, timing and remaining registration checks.

| File | Use |
| --- | --- |
| `kintlo-cover-project.png` | 1800 x 1200 project cover, 3:2 |
| `kintlo-cover-wide.png` | 1920 x 1080 presentation or video title |
| `kintlo-cover-social.png` | 1200 x 630 sharing image |
| `kintlo-brand-palette.png` | Colors, typography and state reference |
| `kintlo-payment-states.png` | Illustrative payment-state specification |
| `kintlo-wordmark.png` | Wordmark and four-tile mark on Cloud |
| Matching `.svg` files | Vector originals with outlined type and text metadata |
| `brand-tokens.json` / `brand-tokens.css` | Palette, type, spacing and new `--kintlo-` variables |
| `contrast-checks.json` | Calculated contrast for the unchanged color pairs |
| `brand-decision.md` / `art-direction.md` | Decision, rollout guidance and provenance |
| `fonts/` | Manrope and DM Sans with their licenses |
| `manifest.json` | Export dimensions, sizes, checksums and status |

The proposed line is **Many agents. Your rules.** Supporting copy is **AI plans. You stay in control.** The name is settled; the line remains a creative recommendation.

The files contain no commercial URL because domain ownership and the launch address are not established. They contain no claim of a hackathon win. The illustrations are not product screenshots or payment evidence.

The primary review is `../../../brief.review.pdf`; implementation directions are in `../../../instruct.review.md`. The original SwarmPay report and brand kit are preserved as the hackathon baseline.
