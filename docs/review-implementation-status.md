## Evidence labels

**Verified on the current deployment** means the check reached the existing public sandbox; its commit was not exposed. **Historical sandbox evidence** keeps the original October/November provider records and their own revisions. **Fixture-tested** means the isolated simulated environment, including stand-in SDK and injected pending outcomes. **Simulated** identifies the configured model, provider, catalog or venue explicitly. **Prepared** means reviewable material without publication; **planned** means no completed implementation.

The current source has 179 passing Java tests and nine hosted browser cases. A fresh public sandbox run separately completed native PayPal approvals, an outside MCP hold, receipt-triggered capture, unchanged payment-request replay and an actual analyst explanation. Fresh exact signed-receipt replay is proved in fixtures; the new live run did not expose the original envelope. [Technical verification](review/evidence/technical/verification.json), [public rehearsal](review/evidence/submission/sandbox-rehearsal.json), [public readiness](review/evidence/submission/public-readiness.json) and [gallery provenance](review/submission/gallery.json) preserve those distinctions.
